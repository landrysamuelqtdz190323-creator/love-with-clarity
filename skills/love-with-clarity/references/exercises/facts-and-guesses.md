# 练习一：把事实与猜测分开

选一件具体事件即可。只写你愿意处理的信息，省略姓名、地址、账号和私密细节；不需要上传聊天截图。这份表不是心理量表。

## 填写

| 项目 | 可以怎样写 |
| --- | --- |
| 我看到或听到的行为 | 发生的时间、实际言语或动作、原有约定 |
| 我的感受和生活影响 | 难过、紧张；影响了睡眠、工作或原有安排 |
| 我正在作出的解释 | “我担心……”或“我猜测……” |
| 我还不知道什么 | 对方当时情境、约定是否理解一致、后续回应 |
| 我需要什么 | 可靠的安排、尊重拒绝、自己的时间等 |
| 下一步最小行动 | 一次澄清、一个请求、一次现实支持或休息 |
| 何时回顾、看什么 | 自然的回顾点；实际行为与自己的体验 |

## 可复制模板

```text
我看到或听到的行为：
我的感受和生活影响：
我正在作出的解释：
我还不知道什么：
我需要什么：
下一步最小行动：
何时回顾、看什么：
```

## 一个虚构示例

行为：我们约好周六见面，周五被取消，之后没有新的安排。

感受：失落，不知道自己的周末怎样安排。

解释：我担心这次见面对TA不重要。

未知：取消原因，以及TA是否希望重新安排。

需要：可以依赖的安排，也能自主决定自己的时间。

行动：在安全允许时澄清一次；暂时安排自己的周末。

回顾：下一次联络后，看是否有具体安排，而不是计算回复速度。

若出现威胁或强迫，不把回顾日期设成必须等满的期限，转到 [安全支持](../safety.md)。本表为原创实践建议：[PRACTICE](../sources.md#practice)。
