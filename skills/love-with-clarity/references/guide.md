# 看清关系，也照顾自己

当你问“TA到底爱不爱我”时，也许还想知道：我的需要有没有被看见？发生的事可以接受吗？我是否还有选择？从其中最具体的一件事开始，会比反复猜测内心更容易行动。

本指南用于成年人的个人反思，不限定性别或关系形式。它不会给爱情打分。场景与练习为原创实践建议，尚未作为心理量表、诊疗方法或效果方案验证；研究来源也不能替某一段关系作决定。

## 先选一个入口

- 有一件事让你反复想：打开 [场景索引](scenarios/index.md)。
- 说不清事实和担心：填写 [事实与猜测练习](exercises/facts-and-guesses.md)。
- 知道难受但不知道怎么说：填写 [需求与边界练习](exercises/needs-and-boundaries.md)。
- 全部精力都被关系占据：从 [七天自我关爱练习](exercises/seven-day-care.md)选一个行动。
- 出现威胁、强迫或暴力：直接看 [安全支持](safety.md)。你不需要证明对方是否爱你，才能关注自己的安全。

## 1. 把经历写成可以核对的事情

“TA从来不在乎我”包含了判断。“我们约好周五见面，TA临时取消，之后没有提出新的时间”更接近可以讨论的行为。写下发生的时间、实际言语或动作、已有约定、后续回应，以及对生活的影响。没有确切次数时就写“我记得有几次”，不必补出精确数字。

你的叙述有价值，也可能不完整。用“根据我目前知道的”保留这个空间；不要求自己查手机、秘密定位或逐分钟记录伴侣。

## 2. 分开事实、感受和解释

| 层次 | 示例 |
| --- | --- |
| 已知行为 | 昨天从下午两点到晚上八点，没有收到回复 |
| 我的感受 | 焦虑、失落，影响了晚饭和原有安排 |
| 我的解释 | 我担心自己对TA不重要 |
| 还不知道 | 当时在做什么；双方是否认可同一个联系频率 |
| 我的需要 | 有可预期的联系，也能正常过自己的生活 |

感受不必先证明才能被认真对待。解释则需要和实际行为、情境、对方说明以及后续变化一起看。列出替代解释并不意味着为持续伤害找借口。

## 3. 看回应和变化

可以围绕几件具体的事观察：对方怎样回应你的需要，怎样对待你的拒绝，约定能否落实，发生伤害后是否承担责任并作出可观察的改变。先看与你的问题有关的一两件事，不必把伴侣放进全天候考核。

一项整合43项纵向伴侣研究的论文分析了关系质量与承诺感、感激、冲突等自我报告变量的关联，也指出关系质量的变化难以从这些变量预测。它帮助我们选择可讨论的主题，不能提供个人爱情判定公式。[JOEL2020](sources.md#joel2020)

“很爱我”和“这段关系适合我”也是两个需要分别思考的问题。你可以同时承认感情、承认某些需要长期没有得到回应。

## 4. 在安全允许时表达需求

把一段表达压缩为具体事件、影响、需要和一个可以协商的请求：

> 当我们约好的见面临时取消，之后也没重新安排时，我会失落。我需要知道我们的约定怎样落实。我们能否一起定一个双方都能做到的新时间？

请求允许对方协商和拒绝。边界说明的是你能接受什么、你会怎样保护自己的时间与生活，例如“如果无法确定时间，我会先安排自己的周末”。避免以惩罚、监控或取消社交来换取回应。

若表达可能引发威胁或报复，先进入安全支持；你不需要完成一段漂亮的沟通才能寻求帮助。

## 5. 选择一个下一步

| 选择 | 可以回顾什么 |
| --- | --- |
| 澄清一次 | 是否得到具体说明，双方预期是否明确 |
| 协商一个小约定 | 约定是否可行，之后实际做了什么 |
| 恢复自己的安排 | 是否有更多休息、支持和自主时间 |
| 寻求外部支持 | 是否有可信任的人或合适的专业资源一起思考 |
| 暂停或结束关系 | 自己的需要与安全怎样安排，现实条件怎样处理 |

这张表不是固定顺序。回顾日期只是帮你重新看事实，例如下次见面后或一周后；出现危险时不等待观察期。是否继续关系由你决定，不用把决定交给 AI 的一句结论。

## 6. 自我关爱可以很具体

今天吃一顿饭、结束一次无休止的刷新、联系一个可信任的人、恢复自己的兴趣，都可以是开始。关爱自己不要求马上振作，也不要求完全不需要别人。

自我关爱相关研究为温和对待自身困难提供了背景。本项目的七天安排和练习是便于使用的编辑设计，不是研究中的治疗方案，不承诺治疗焦虑、抑郁或创伤。[CARE2019](sources.md#care2019)

## 关于安全和资料

强迫、威胁、暴力和控制行为需要认真对待，不用先确定对方的人格或动机。WHO 将性强迫、心理伤害和控制行为纳入亲密伴侣暴力的描述；这份来源主要讨论针对女性的暴力，本项目的支持原则向所有性别开放。[WHO2026](sources.md#who2026)
