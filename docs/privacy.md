# 隐私与资料处理

## 阅读网页

本版网页没有后端、分析追踪、外部字体或 AI 接口。搜索与练习在当前页面运行；不发送表单、不写入 localStorage、Cookie 或 IndexedDB。它不读取聊天软件、相册或联系人。

填写内容不会成为可分享的链接参数。切换练习会保留当前页面中的填写，方便继续编辑；关闭页面后没有本项目的持久化恢复功能，但浏览器自身可能保留页面状态。使用“清空全部填写”可清空页面表单。

复制或下载需要你主动点击；下载文件会保存在你选定的位置，剪贴板内容可能由操作系统或其他应用处理。不要把报告误认为匿名文件。

若将网页托管到公共网站，托管方可能记录访问请求等日志。上述“不上传填写”描述的是本项目提供的程序，不能代替托管方或浏览器的隐私政策。

## 在 Codex 或 WorkBuddy 中使用

Skill 文件在本地，不等于模型推理完全离线。宿主可能将输入交给其 AI 服务，并可能保存会话；数据保存、训练使用与删除选项以平台和账号设置为准。

本 Skill 不自行读取通讯软件或其他个人文件，不建立自己的数据库，不自动上传材料，也不替你联系伴侣。宿主仍有自己的工具与权限，安装 Skill 不会收回平台已有权限，也不改变云端设置。

可以只用概括事件，不提供姓名、账号、位置、工作单位、亲密照片或可识别细节。用户不愿补充时，Skill 应保留未知并提供有限整理。

## 公开协作

公开 Issues 和 Pull Requests 会被其他人看到，可能长期留在平台历史中。只提交项目缺陷、虚构或充分去识别化且获授权的例子；不要上传个人聊天、证件、地址、他人隐私或未获许可的故事。

如果担心当前设备或通信受到监控，先看 [安全支持](../skills/love-with-clarity/references/safety.md)，不要为使用本项目输入具体安全计划。
